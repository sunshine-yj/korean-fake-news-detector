# 데이터셋 명세서 — FakeNews_balanced_v5

> ⚠️ **경고**: 본 데이터셋의 `is_fake=1` 레코드는 연구 목적으로 LLM이 인위 생성한 **허위 텍스트**입니다. 실제 사실이 아니며, 사실 정보로 인용·유통·재배포되어서는 안 됩니다. 원본이 된 실제 기사에 등장하는 인물·기관·수치는 조작된 상태이므로, 해당 대상에 대한 사실 진술로 해석해서는 안 됩니다.

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 데이터셋명 | FakeNews_balanced_v5 |
| 버전 | v5 |
| 목적 | LLM 생성 한국어 가짜뉴스 탐지 모델의 학습 및 평가 |
| 언어 | 한국어 |
| 총 규모 | 10,000건 |
| 클래스 | 진짜 5,000 / 가짜 5,000 (1:1 균형) |
| 구축 기관 | 선문대학교 |
| 구축 기간 | (수집 시작일 ~ 종료일 기입) |
| 라이선스 | 비상업적 연구 목적 이용 (원문 기사 저작권은 각 언론사 귀속) |

## 2. 구축 동기

기존 공개 데이터셋은 사람이 작성한 가짜뉴스 또는 특정 시점의 기사에 편중되어 있어, 최신 LLM이 생성한 가짜뉴스에 대한 탐지 성능을 측정하기 어렵다. 본 데이터셋은 다음 세 조건을 만족하도록 설계되었다.

- **최신성**: 학습 데이터 시점 이후의 실제 기사를 원본으로 사용
- **유형 통제**: 하나의 가짜 기사에 단일 조작 유형만 적용
- **분포 균형**: 진짜/가짜 및 조작 유형 간 균형 유지

## 3. 구성

### 3.1 분할

| 분할 | 진짜 | 가짜 | 합계 |
|---|---:|---:|---:|
| Train | 4,000 | 4,000 | 8,000 |
| Test | 1,000 | 1,000 | 2,000 |
| **합계** | **5,000** | **5,000** | **10,000** |

### 3.2 조작 유형별 분포 (Test 기준)

| prompt_type | 유형명 | 조작 대상 | Test 건수 |
|---|---|---|---:|
| 1 | 수치 변경 | 통계·금액·인원·비율 등 정량 정보 | 200 |
| 2 | 고유명사 치환 | 인물명·기관명·지역명 | 200 |
| 3 | 출처 익명화 | 명시적 출처 → 익명 표현 | 200 |
| 4 | 인과 왜곡 | 사건 간 인과관계 구조 | 200 |
| 5 | 동사 반전 | 서술어의 의미 극성 | 200 |

> Train 분할의 유형별 분포도 동일하게 균형을 유지하며, 라운드로빈 프롬프트 순환 방식으로 확보했다.

### 3.3 출처 언론사

연합뉴스, SBS, 동아일보, 한겨레, JTBC 등 (언론사별 수집 건수는 `data/stats/source_distribution.csv` 참조)

### 3.4 카테고리

정치 · 경제 · 사회 · 국제 · IT/과학 등 (분포는 `data/stats/category_distribution.csv` 참조)

## 4. 스키마

| 컬럼 | 타입 | 설명 |
|---|---|---|

| `title` | VARCHAR | 원본 제목 |

## 5. 구축 절차

### 5.1 진짜 기사 수집

n8n 워크플로를 통해 RSS 피드 및 네이버 뉴스 API로 기사를 수집하고, HTML 본문을 파싱해 MySQL `ARTICLES` 테이블에 적재한다. 중복은 URL 기준으로 제거한다.

### 5.2 전처리

`content` → `content_clean` 변환 시 다음 패턴을 정규식으로 제거·정규화한다.

- 기자 바이라인 (`OOO 기자 =`, `OOO 특파원 =`)
- 저작권 고지 (`무단전재 및 재배포 금지` 등)
- 이스케이프된 따옴표 (`\"`) 및 특수 기호
- 연속 공백 및 개행 정규화

### 5.3 가짜 기사 생성

수집된 진짜 기사를 원본으로, GPT-5-mini에 유형별 프롬프트를 적용해 생성한다. 프롬프트는 라운드로빈으로 순환하여 유형 간 균형을 유지한다.

생성 시 준수한 제약:

- **단일 유형 원칙**: 하나의 기사에 하나의 조작 유형만 적용
- **문체 보존**: 조작 대상 외의 문장 구조·어투·기사 형식은 원문 유지
- **길이 유지**: 원문과 유사한 분량 유지

### 5.4 검수

생성 결과 중 조작이 적용되지 않았거나 원문과 동일한 사례, 생성이 거부된 사례를 제외한 뒤 최종 균형 분할을 구성했다.

## 7. 공개 범위

저작권 및 오정보 확산 방지를 위해 **전문(full text)은 공개하지 않는다.**

| 항목 | 공개 여부 |
|---|---|
| 진짜 기사 메타데이터 (ID, URL, 언론사, 발행일) | 공개 |
| 진짜 기사 본문 전문 | **비공개** (URL을 통해 각자 수집) |
| 가짜 기사 본문 전문 | **비공개** (요청 시 연구 목적 한정 제공) |
| 유형별 예시 샘플 | 유형당 5건, `data/samples/` |
| 통계 및 분포 | 공개 |

## 8. 알려진 한계

- **원본 편향**: 특정 기간·언론사에 수집이 집중되어 있어 시사 이슈 분포에 편향이 존재한다.
- **생성 모델 의존성**: 가짜 기사가 단일 LLM(GPT-5-mini)으로 생성되어, 해당 모델 고유의 문체적 흔적이 탐지 단서로 작용했을 가능성을 배제할 수 없다.
- **유형 단순화**: 실제 가짜뉴스는 여러 조작이 복합적으로 나타나나, 본 데이터셋은 유형별 분석을 위해 단일 유형으로 통제했다.
- **원리적 탐지 한계**: 유형 1(수치 변경)과 유형 5(동사 반전)는 텍스트 내부 단서만으로는 판별이 불가능한 사례를 포함한다.

## 9. 이용 시 유의사항

- 본 데이터셋은 **탐지 모델 연구 및 미디어 리터러시 교육** 목적으로만 이용해야 한다.
- 가짜 기사 텍스트를 외부 서비스·SNS 등에 원문 그대로 게시해서는 안 된다.
- 생성 모델 학습 데이터로 사용할 경우, 허위 정보 생성 능력을 강화할 수 있으므로 권장하지 않는다.
- 진짜 기사 본문의 저작권은 각 언론사에 있으며, 재배포 시 해당 언론사의 이용약관을 따라야 한다.
